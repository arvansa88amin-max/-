# امین‌مسج | AminMsg

یک سرویس فارسی برای ساخت لینک اختصاصی و دریافت پیام ناشناس.

## اجرا

1. وابستگی‌ها را نصب کنید: `npm install`
2. برنامه را اجرا کنید: `npm run dev`
3. بخش وب و سرور برنامه توسط محیط اجرا مدیریت می‌شوند. برای انتشار، همان محیط متغیر `PORT` را به‌صورت خودکار تنظیم می‌کند.

## ساختار و امنیت

- گذرواژه‌ها با `scrypt` و نمک تصادفی نگهداری می‌شوند.
- نشست‌ها با شناسه‌های تصادفی و هش‌شده ذخیره می‌شوند.
- تمام پرس‌وجوهای داده‌ای پارامتری هستند.
- پیام‌های عمومی سقف ۷۰۰ کاراکتر و محدودیت ارسال دارند.
- پیام‌ها و حذف آن‌ها فقط برای صاحب حساب قابل دسترس هستند.
- هویت فرستنده در دادهٔ پیام ذخیره یا نمایش داده نمی‌شود.

## مسیرها

`/`، `/login`، `/register`، `/dashboard`، `/messages`، `/account`، `/u/:username`، `/privacy`، `/terms`

## بررسی مسیر اصلی

1. در `/register` یک حساب بسازید.
2. به داشبورد بروید و لینک اختصاصی را کپی کنید.
3. لینک `/u/username` را در یک پنجرهٔ دیگر باز کنید و پیام بفرستید.
4. به صندوق پیام‌ها برگردید؛ پیام بلافاصله نمایش داده می‌شود.
5. پیام را حذف کنید و ناپدید شدن آن را بررسی کنید.
